# سُحُب التقنية | so7ob — الموقع الرسمي

> **تُمطِرُ حلولًا ذكية.**

المستودع الرسمي للكود المصدري والتوثيق وسجل التغييرات الخاص بالموقع التعريفي لشركة **سُحُب التقنية (so7ob)** — شركة برمجيات ناشئة تستهدف الشركات الصغيرة والمتوسطة ورواد الأعمال في السوق العربي، وتساعدهم على تحويل أفكارهم واحتياجات أعمالهم إلى منتجات رقمية سهلة الاستخدام وقابلة للتطوير.

## تعريف المشروع

- **النوع:** موقع تعريفي متعدد اللغات (عربي أولًا + نسخة إنجليزية كاملة) مع نموذج استقبال طلبات المشاريع.
- **اللغات:** العربية (RTL) والإنجليزية (LTR) عبر مسارات `/ar/` و`/en/`.
- **الهدف:** فهم الخدمات وطريقة العمل خلال أول تصفح، وتحويل الزائر المناسب إلى استفسار أو طلب عرض سعر.
- **نطاق الخدمات المعروضة:** تطوير المواقع وتطبيقات الويب، تطبيقات الجوال، الأنظمة الإدارية، تصميم الواجهات وتجربة المستخدم، أتمتة الأعمال وتكامل الذكاء الاصطناعي، الصيانة والدعم.

## المنهجية

- يتم التطوير عبر **Issues** وفروع عمل مستقلة و**Pull Requests** تمر بالفحوص قبل الدمج — راجع `CONTRIBUTING.md` و`AGENTS.md` (يُضيفان مع أول فرع تطوير).
- فرع `main` مخصص للعمل المقبول والمستقر؛ التغييرات تمر عبر طلبات سحب مع فحوص آلية.
- لا يُرفع إلى هذا المستودع: الأسرار، ملفات البيئة الفعلية، بيانات العملاء، أو أي بيانات حقيقية.

## الحالة

🚧 **قيد التهيئة الأولية** — جارٍ تنفيذ الموقع الكامل داخل فرع تطوير مستقل وسيُقدَّم عبر Pull Request للمراجعة.
