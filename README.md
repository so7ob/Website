# سُحُب التقنية | so7ob — الموقع الرسمي

> **تُمطِرُ حلولًا ذكية.**

الموقع التعريفي لشركة **سُحُب التقنية (so7ob)** — شركة برمجيات ناشئة تستهدف الشركات الصغيرة والمتوسطة ورواد الأعمال في السوق العربي، وتحوّل أفكارها واحتياجات أعمالها إلى منتجات رقمية سهلة الاستخدام وقابلة للتطوير.

## ما يحويه الموقع

| الصفحة | المسار (عربي) | المحتوى |
|---|---|---|
| الرئيسية | `/ar` | واجهة افتتاحية، الخدمات، ما يميز طريقة العمل، أعمال توضيحية، مراحل التنفيذ، أسئلة مختارة، دعوة ختامية |
| من نحن | `/ar/about` | التعريف، الرؤية، الرسالة، القيم، المبادئ |
| الخدمات | `/ar/services` | ست خدمات مفصلة: التعريف، لمن تناسب، المشكلات، المخرجات، زر طلب يحدد الخدمة تلقائيًا |
| أعمالنا | `/ar/works` | ثلاث حالات توضيحية معلنة بصراحة أنها ليست أعمال عملاء (تصور تصميمي + نموذج تفاعلي + مخطط سير عمل) |
| آلية العمل | `/ar/process` | أربع مراحل بدور العميل ومخرجاته، وطريقة إدارة التغييرات |
| الأسئلة الشائعة | `/ar/faq` | 9 إجابات فعلية بأكورديون متاح بلوحة المفاتيح |
| التواصل | `/ar/contact` | نموذج طلب مشروع بحفظ دائم وحمايات، وإشعار خصوصية، وخطوات ما بعد الإرسال |

كل صفحة لها نظير إنجليزي تحت `/en/…` مع RTL/LTR صحيحين، ومبدّل لغة يحفظ الاختيار في كوكي.

## التقنيات وسبب اختيارها

- **Next.js 16 (App Router) + TypeScript**: موقع تعريفي ثابت الأداء مع نموذج خادمي في المشروع نفسه — بنية واحدة بلا خدمات منفصلة.
- **Tailwind CSS 4 + shadcn/ui**: نظام تصميم متسق بألوان الهوية، مع مكوّنات متاحة الجاهزية (Accordion، Select…).
- **Prisma + SQLite**: تخزين دائم لطلبات النموذج بصفر إعداد خارجي. عند النشر الفعلي بضغط أعلى، يُستبدل provider بـ PostgreSQL/MySQL بتغيير ملف المخطط ورابط البيئة فقط.
- **`[locale]` ديناميكي** بدل مكتبات i18n: لغتان فقط ومحتوى ثابت — توليد صفحات ساكن لكل لغة، وجذر تخطيط واحد يضبط `lang/dir` بشكل صحيح.
- **خطوط IBM Plex** (Sans Arabic + Sans) عبر حزم npm fontsource — بلا اعتماد على شبكة زمن البناء.
- **Vitest**: اختبارات منطق التحقق ومنع التكرار وتكافؤ الترجمات وسلوك الواجهة.

│   ├── components/              # site/ (ترويسة، تذييل، شعار…) home/ pages/ works/ form/

## التشغيل المحلي

المتطلبات: [Bun](https://bun.sh) (أو Node 20+ مع npm).

```bash
# 1) الاستنساخ
git clone https://github.com/so7ob/Website.git
cd Website

# 2) التبعيات (بملف القفل)
bun install

# 3) متغيرات البيئة
cp .env.example .env   # القيم الافتراضية تكفي للتشغيل المحلي

# 4) إنشاء قاعدة البيانات
bun run db:push

# 5) التشغيل
bun run dev            # http://localhost:3000
```

## الفحوص والبناء

```bash
bun run lint         # ESLint
bun run typecheck    # tsc --noEmit
bun run test         # Vitest (تحقق، حد معدل، تكافؤ الترجمات، أكورديون)
bun run build        # بناء الإنتاج
```

تُشغَّل الفحوص نفسها آليًا على كل Pull Request عبر `.github/workflows/ci.yml`.

## تعديل المحتوى والترجمات

- **النصوص**: كل المحتوى في `src/content/ar.ts` و`src/content/en.ts` وفق بنية واحدة معرّفة في `src/content/types.ts`. عدّل اللغتين معًا — اختبار `i18n parity` يفشل عند نقص أي مفتاح.
- **بيانات التواصل والروابط**: `src/config/site.ts`. الحقول الفارغة **لا تظهر** في الواجهة إطلاقًا؛ املأ البريد/الهاتف/العنوان عند توفر بيانات معتمدة فحسب.
- **ألوان الهوية**: رموز `:root` في `src/app/globals.css`.
- **الشعار**: الملفات في `public/` (`logo.png` أسود للأسطح الفاتحة، `logo-white.png` للأسطح الداكنة).

## إعدادات نموذج طلب المشروع

يعمل النموذج بالحفظ الدائم دون أي خدمة خارجية:

1. تحقق مشترك في الواجهة والخادم (`src/lib/validation.ts`) — رموز أخطاء مترجمة لكل حقل.
2. حمايات: حقل عسل مخفي، رصد إرسال آلي سريع، حد معدل (3 خلال 10 دقائق، 8 يوميًا لكل بصمة شبكة)، وكشف تكرار (نفس البريد + الوصف خلال 30 دقيقة).
3. الحفظ في جدول `ProjectRequest` مع رمز مرجعي `S7-XXXXXXX` يُعرض للمرسل.
4. **إشعار المسؤول (اختياري)**: ضبط `NOTIFY_WEBHOOK_URL` في `.env` يرسل POST JSON عند كل طلب جديد. غيابه لا يمنع الحفظ ولا يحاكي نجاحًا.

القيم الافتراضية في `.env.example`:

```env
DATABASE_URL="file:../db/custom.db"
NEXT_PUBLIC_SITE_URL="http://localhost:3000"
NOTIFY_WEBHOOK_URL=""
```

## قيود معلومة

- **SQLite + حد معدل داخل الذاكرة**: مناسب للانطلاق ومثيل واحد؛ عند التوسع الأفقي استبدل المخزن (`src/lib/ratelimit.ts`) بمخزن مشترك وprovider قاعدة أقوى.
- **لا لوحة إدارة**: مراجعة الطلبات تتم من القاعدة مباشرة؛ إضافة لوحة تحتاج تكليفًا صريحًا.
- **الأعمال المعروضة توضيحية** وليست أعمال عملاء — هذا معلن في الصفحة نفسها، وأي عمل فعلي يُعرض بإذن عميله.
- **بيانات التواصل فارغة افتراضيًا** حتى تتوفر قنوات معتمدة؛ لا تُخترع قيم.

## إمكانية الوصول واللغة

- استهداف WCAG 2.2 AA: تباين مُختبر للألوان، تسميات حقول، تركيز مرئي موحد، تنقل كامل بلوحة المفاتيح، احترام `prefers-reduced-motion`، عزل اتجاه المحتوى المختلط (`.ltr-isolate`).
- عناوين ووصف مستقلان لكل صفحة ولغة، `hreflang` بديل، `sitemap.xml`، `robots.txt`، وبيانات Open Graph. لا بيانات منظمة (JSON-LD) لعدم تأكد بيانات الشركة.
